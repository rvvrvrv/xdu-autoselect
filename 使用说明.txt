   西电选课助手 · 使用说明
════════════════════════════════════════════

【这个工具是干什么的】

到了抢课时间，手速再快也拼不过别人。
这个工具会在开课瞬间自动帮你“点选课程 + 确认”，
比手速快得多。登录和验证码永远由你自己完成，
工具不保存、不外传你的任何账号信息。


【开始前你只需要】

1. 一台 Windows 电脑（Win10 / Win11）
2. 电脑上有 Edge 或 Chrome 浏览器（一般都有）
3. 会双击鼠标


【第一次使用（跟着做，共 8 步）】

第 1 步：双击「一键启动.bat」
   → 会弹出一个命令行窗口，请不要关它。
   → 第一次运行会自动下载需要的小组件，等 1~2 分钟。

第 2 步：命令行窗口出现“配置向导”后，直接按回车
   （默认选模式 1：自动抓取课程列表）。

第 3 步：浏览器自动弹出 → 在网页里输入学号、密码、
   验证码 → 点【登 录】。
   ★ 登录必须你自己来，工具不会替你输入或点击，也不会记录任何你的账号信息。

第 4 步：登录成功后，在网页里点进去你要抢课的那个轮次
   （例如“第X轮方案内课程”旁边的【开始选课】）。

第 5 步：回到命令行窗口稍等，工具会自动列出
   这个轮次里的所有课程和老师。

第 6 步：输入想抢课程的编号，用空格隔开，再按回车。
   例如想抢第 1、3、5 门，就输入：1 3 5

第 7 步：对每门课，再输入教学班（老师）的编号：
   → 第一个输入的是你最想要的，后面的是备选
     （例如输入 2 1 = 最想要 2 号班，抢不到就 1 号班）
   → 直接按回车 = 这门课先不抢了。

第 8 步：看一眼配置清单，没问题按回车确认。
   → 看到“已写入 config.json”就配置完成了


【正式抢课那天怎么做】

1. 开抢时间前 5~10 分钟（可以提前，防止到时候登录的人太多登不进去），双击「一键启动.bat」。
2. 浏览器弹出后登录，点进对应的轮次。
3. 工具会自动读取学校公布的开课时间，倒计时等待。
4. 时间一到自动点选抢课，你盯着就行。
★ 全程不要关闭命令行窗口；电脑别锁屏断网。


【抢课进行中，你会看到什么】

  “⚡ 预定位：……”  → 提前帮你把课找好了，稳住
  “⏰ 到点，开始行动！” → 开始抢了！
  “✓ 选课成功 / 视为已进入选课队列” → 这门课稳了
  “✗ 明确失败：……” → 这门没抢到，工具会自动多试几次
  “人工接管” → 自动没成功；你可以自己在浏览器里手动选，
               选完回命令行窗口按一下回车继续


【常见问题】

问：命令行窗口里的中文变成乱码了？
答：新版已修复。若还出现，请截图告诉分享给你的人。

问：输入编号变成了 22、1100？
答：新版已修复。若还出现，请反馈。

问：浏览器没弹出来？
答：确认电脑装有 Edge 或 Chrome 浏览器。

问：抢到一半提示重新登录？
答：网络波动导致掉线。在浏览器里重新登录一次，
   工具会自动接着往下走。

问：想换课程重新配置？
答：打开本文件夹，删除 config.json 这个文件，
   再双击「一键启动.bat」重新走一遍向导即可。

问：开课时间要自己填吗？
答：不用。工具自动读取学校公布的轮次时间。

问：出现“✗ 脚本异常”？
答：看提示内容。多数情况直接关掉窗口重新双击启动即可，
   已完成的步骤会自动跳过。解决不了就把命令行窗口截图发人。


【重要提醒】

· 工具已尽力应对网络波动与掉线（自动提示重登、断点续跑），
  但它只负责“点选抢课”这一步；
  因网络或其他原因导致未能按预期抢到课程的，
  不在本工具能力范围内，请知悉。
· 请遵守学校选课规定；验证码请永远自己输入。
· 本工具仅供个人学习与个人自动化使用。
